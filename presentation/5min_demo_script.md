# 5분 발표/시연 스크립트

## 0:00 - 문제 제기

반도체 장비 장애 대응은 알람 코드 하나만 보는 문제가 아닙니다. HMI 메시지, EtherCAT 상태, DI/DO 신호, 매뉴얼, 과거 정비 이력을 동시에 해석해야 합니다. 신입 엔지니어에게 이 과정은 어렵고, 선임의 암묵지가 문서화되지 않는 문제가 있습니다.

## 0:40 - 제약 설명

하지만 실제 반도체 현장은 보안이 강하고, 회사마다 장비와 알람 체계가 다릅니다. 또한 AI가 직접 장비를 제어하면 안전 책임 문제가 생깁니다. 그래서 저는 범용 자동제어 AI가 아니라 내부망 기반 읽기 전용 트러블슈팅 AI로 설계했습니다.

## 1:20 - 시스템 소개

FabMind Agent는 Load Port / FOUP Clamp 장비군에 특화된 Agentic AI 플랫폼입니다. 알람, DI/DO, EtherCAT 상태, 매뉴얼 근거, 정비 이력을 연결해서 원인 후보, 점검 절차, 보고서 초안을 생성합니다.

## 2:00 - 시연

LP-01 장비에서 LP-CLAMP-014 알람을 선택합니다. DO_CLAMP_SOL은 ON인데 DI_CLAMP_DONE은 OFF입니다. 최근 sensor bracket 조정 이력을 입력하고 분석을 실행합니다.

## 2:40 - 결과 설명

Agent는 clamp done sensor misalignment를 1순위로 제시합니다. 단순 답변이 아니라 알람 코드, I/O 상태, 매뉴얼 chunk, 최근 작업 이력을 evidence로 연결합니다.

## 3:20 - 안전/승인 구조

사용자가 인터락 무시나 강제 동작을 요청하면, AI는 직접 수행 방법을 제공하지 않고 안전 가드레일로 차단합니다. 필요한 경우 선임 승인 플로우로 넘깁니다.

## 4:00 - 보고서/감사로그

체크리스트 수행 후 보고서 초안이 생성되고, 선임이 승인하면 audit log가 남습니다. 이 구조는 현업에서 책임 추적과 품질 관리에 중요합니다.

## 4:40 - 마무리

이 프로젝트의 핵심은 AI가 모든 것을 자동으로 해결한다는 과장이 아니라, 반도체 현장의 보안·장비 이질성·안전 책임을 고려해 근거 기반으로 엔지니어를 보조하는 실제적인 시스템을 만든 것입니다.
