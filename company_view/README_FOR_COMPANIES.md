# FabMind Agent - Company Reviewer Brief

## What to evaluate

FabMind Agent is a portfolio-grade project showing the applicant's ability to combine:

- semiconductor equipment domain understanding
- backend data modeling
- frontend SaaS UI design
- agentic workflow design
- safety/security thinking
- GitHub-based engineering discipline

## What makes it relevant

The project does not claim to control real equipment. Instead, it addresses the realistic first step: read-only troubleshooting support with evidence and auditability.

## Code review focus

1. deterministic agent rules
2. evidence linking
3. API contract
4. DB schema
5. UI state handling
6. tests and CI
7. README clarity

## Suggested interview questions

1. Why did you choose Load Port / FOUP Clamp instead of all semiconductor equipment?
2. Why is LLM not the primary decision engine?
3. How do you prevent unsafe recommendations?
4. How would you deploy this inside a secure factory network?
5. How would you adapt it to another equipment family?
